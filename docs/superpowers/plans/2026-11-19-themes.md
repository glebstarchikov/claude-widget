# Color Themes and New Year Hat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the critter's color a choice (Claude orange by default), make "needs you" a red dot plus pulse in every theme, and give the critter a winter hat from Dec 15 to Jan 7.

**Architecture:** Pure color math, the theme table and the date window live in `ClaudeWidgetCore` (unit-tested). Hat and dot geometry live beside the critter's in `CritterGeometry`. The app keeps one `ThemeStore` (an `ObservableObject`) that `Theme.swift` reads, so every existing call site of `Theme` switches palettes in one place.

**Tech Stack:** Swift 5 mode, SwiftPM, AppKit + SwiftUI, macOS 26, XCTest.

**Spec:** `docs/superpowers/specs/2026-11-19-themes-design.md` (and `2026-11-17-notch-hub-design.md` for the hub it changes).

## Global Constraints

- macOS 26, Swift 5 language mode, SwiftPM, no new dependencies.
- Presets (light / dark): Claude `#C36B4E` / `#D97757` (default); Lime `#5E9425` / `#6FAE2C`; Mint `#1C9571` / `#1FA67E`; Ocean `#2C7FE0` / `#2C7FE0`; Indigo `#4B46F5` / `#8A86FF`; Violet `#9459E6` / `#9459E6`; Rose `#DB4F84` / `#DB4F84`; System `#1D1D1F` / `#F5F5F7` with the hub accent `NSColor.controlAccentColor`. Order in Settings: Claude, Lime, Mint, Ocean, Indigo, Violet, Rose, System, Custom.
- Contrast rule: ≥ 3:1 (WCAG relative luminance) against `#ECECEE` (light bar) / `#26262A` (dark bar); otherwise mix toward black (light) / white (dark) in 5 % steps until it passes.
- "Needs you" = pulse + `NSColor.systemRed` dot at the critter's top-right, separated from the body by a transparent gap (cut out, not a colored ring). Reduce Motion: no pulse, the dot stays. Text/marks meaning "needs you" use the same red.
- Asleep: faint gray at 45 % (unchanged). Ready/waiting: theme color at 70 %. Working: theme color at 100 %.
- Allow fill = theme accent; its text is white unless white has less than 3:1 contrast against the fill, then `#1D1D1F`.
- Hat: cone `#D93A3A`, brim and pom white, hairline `rgba(0,0,0,0.18)`; centered on the body, tip flops so the pom hangs slightly to the side (Gleb's pick). Active Dec 15 – Jan 7 inclusive, local calendar, and only while the "New Year hat" setting is on (default on).
- UserDefaults keys: `theme` (default `"claude"`), `themeCustomColor` (default `"#2BB3C0"`), `newYearHat` (default `true`).
- The state logic (aggregate state, pills, approvals) does not change, only how states are drawn.
- Never touch the Keychain, the approval socket or `~/.claude/claude-widget` from tests.

## Review Focus

1. **A custom color that is near-white or near-black** must still reach 3:1 on both bars. Pinned in Task 1 (`testCustomExtremesAreFittedOnBothBars`).
2. **The hat and the dot at real 18 pt size** must not clip and must leave the critter readable, on light and dark bars, together. Pinned in Task 2 (geometry bounds tests + real-size renders checked by eye).
3. **Changing the theme while the critter is pulsing or asleep** must recolor the menu bar at once, not at the next state change. Pinned in Task 3 (`refresh()` wired to the store; checked by screenshot in Task 4).
4. **The date window across midnight** (Dec 14 → 15 and Jan 7 → 8) while the app runs. Pinned in Task 1 (boundary tests) and Task 3 (day-change notification).
5. **System theme with a changed macOS accent color / appearance**: the hub follows without a relaunch. Pinned in Task 3 (accent read from `controlAccentColor` at draw time, never cached).

final class ThemeColorsTests: XCTestCase {
    func testHexRoundTripAndRejects() {
        XCTAssertEqual(RGB(hex: "#d97757")?.hex, "#D97757")
        XCTAssertNil(RGB(hex: "D97757")); XCTAssertNil(RGB(hex: "#D9775")); XCTAssertNil(RGB(hex: "#GG7757"))
    }
    func testContrastKnownValues() {
        let w = RGB(hex: "#FFFFFF")!, b = RGB(hex: "#000000")!
        XCTAssertEqual(w.contrast(with: b), 21, accuracy: 0.01)
        XCTAssertEqual(RGB(hex: "#D97757")!.contrast(with: ThemePalette.darkBar), 4.83, accuracy: 0.02)
    }
    func testPresetTableIsExact() {
        let expected: [ThemeID: (String, String)] = [
            .claude: ("#C36B4E", "#D97757"), .lime: ("#5E9425", "#6FAE2C"), .mint: ("#1C9571", "#1FA67E"),
            .ocean: ("#2C7FE0", "#2C7FE0"), .indigo: ("#4B46F5", "#8A86FF"), .violet: ("#9459E6", "#9459E6"),
            .rose: ("#DB4F84", "#DB4F84"), .system: ("#1D1D1F", "#F5F5F7")]
        for (id, (l, d)) in expected {
            let p = ThemePalette.pair(for: id, custom: RGB(hex: "#000000")!)
            XCTAssertEqual(p.light.hex, l, "\(id) light"); XCTAssertEqual(p.dark.hex, d, "\(id) dark")
        }
    }
    func testEveryPresetMeetsThreeToOne() {
        for id in ThemeID.allCases where id != .custom {
            let p = ThemePalette.pair(for: id, custom: RGB(hex: "#000000")!)
            XCTAssertGreaterThanOrEqual(p.light.contrast(with: ThemePalette.lightBar), 3, "\(id)")
            XCTAssertGreaterThanOrEqual(p.dark.contrast(with: ThemePalette.darkBar), 3, "\(id)")
        }
    }
    func testCustomExtremesAreFittedOnBothBars() {
        for hex in ["#FFFFFF", "#FFF2A8", "#000000", "#101030", "#2BB3C0"] {
            let p = ThemePalette.pair(for: .custom, custom: RGB(hex: hex)!)
            XCTAssertGreaterThanOrEqual(p.light.contrast(with: ThemePalette.lightBar), 3, hex)
            XCTAssertGreaterThanOrEqual(p.dark.contrast(with: ThemePalette.darkBar), 3, hex)
        }
    }
    func testCustomThatAlreadyPassesIsUntouched() {   // negative: fitting must not drift a good color
        let p = ThemePalette.pair(for: .custom, custom: RGB(hex: "#2C7FE0")!)
        XCTAssertEqual(p.light.hex, "#2C7FE0"); XCTAssertEqual(p.dark.hex, "#2C7FE0")
    }
    func testOnAccentPicksTheHigherContrast() {
        XCTAssertEqual(ThemePalette.onAccent(RGB(hex: "#4B46F5")!), ThemePalette.white)
        XCTAssertEqual(ThemePalette.onAccent(RGB(hex: "#6FAE2C")!), ThemePalette.darkText)
    }
    func testNewYearWindowBoundaries() {
        var cal = Calendar(identifier: .gregorian); cal.timeZone = TimeZone(identifier: "Europe/Amsterdam")!
        func d(_ y: Int, _ m: Int, _ day: Int, _ h: Int = 12) -> Date {
            cal.date(from: DateComponents(year: y, month: m, day: day, hour: h))!
        }
        XCTAssertFalse(NewYear.isActive(on: d(2026, 12, 14, 23), calendar: cal))
        XCTAssertTrue(NewYear.isActive(on: d(2026, 12, 15, 0), calendar: cal))
        XCTAssertTrue(NewYear.isActive(on: d(2026, 12, 31), calendar: cal))
        XCTAssertTrue(NewYear.isActive(on: d(2027, 1, 1), calendar: cal))
        XCTAssertTrue(NewYear.isActive(on: d(2027, 1, 7, 23), calendar: cal))
        XCTAssertFalse(NewYear.isActive(on: d(2027, 1, 8, 0), calendar: cal))
        XCTAssertFalse(NewYear.isActive(on: d(2026, 7, 1), calendar: cal))
    }
}

func testHatAndBadgeStayInsideTheCanvas() {
    let canvas = CGRect(origin: .zero, size: CritterGeometry.canvas)
    XCTAssertTrue(canvas.contains(CritterGeometry.hatCone().boundingBoxOfPath))
    XCTAssertTrue(canvas.contains(CritterGeometry.hatBrim))
    let pom = CritterGeometry.hatPom
    XCTAssertTrue(canvas.contains(CGRect(x: pom.center.x - pom.radius, y: pom.center.y - pom.radius,
                                         width: pom.radius * 2, height: pom.radius * 2)))
    let b = CritterGeometry.badge, r = b.radius + CritterGeometry.badgeGap
    XCTAssertTrue(canvas.contains(CGRect(x: b.center.x - r, y: b.center.y - r, width: r * 2, height: r * 2)))
}
func testPomHangsToTheSideOfTheConeCenter() {
    let cone = CritterGeometry.hatCone().boundingBoxOfPath
    XCTAssertNotEqual(CritterGeometry.hatPom.center.x, cone.midX, accuracy: 0.5)
}
func testBadgeNeverTouchesTheHat() {   // negative: the dot must stay readable with the hat on
    let b = CritterGeometry.badge, p = CritterGeometry.hatPom
    let gap = hypot(b.center.x - p.center.x, b.center.y - p.center.y) - b.radius - p.radius
    XCTAssertGreaterThan(gap, CritterGeometry.badgeGap)
    XCTAssertFalse(CritterGeometry.hatCone().boundingBoxOfPath.intersects(
        CGRect(x: b.center.x - b.radius, y: b.center.y - b.radius, width: b.radius * 2, height: b.radius * 2)))
}
func testBodyIsUnchangedWithoutHat() {   // negative: existing poses keep the official geometry
    XCTAssertEqual(CritterGeometry.bodyRects(pose: .idle)[0], CGRect(x: 3, y: 5, width: 17.998, height: 12.079))
}

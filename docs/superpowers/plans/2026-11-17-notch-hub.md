# Notch Hub (project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the popover and one-line notch peek with a Liquid Glass hub under the notch that shows live agents and Claude usage limits, and lets Gleb answer Claude's permission prompts from the notch.

**Architecture:** Pure, tested logic goes in `ClaudeWidgetCore` (usage parsing, credential parsing, approval wire format, approval policy, Unix-socket client). The hook binary gains one synchronous path for `PermissionRequest` that talks to the app over a Unix socket. The app replaces `NotchPanelController`/`PopoverView` with one hub panel (hidden / pill / expanded), adds a Settings window, a usage poller and an approval server.

**Tech Stack:** Swift 5 language mode, SwiftPM (no Xcode project), AppKit + SwiftUI on macOS 26 (Liquid Glass: `glassEffect(_:in:)`, `GlassEffectContainer`, `.buttonStyle(.glass/.glassProminent)`), Foundation `URLSession`, Darwin sockets, XCTest.

**Spec:** `docs/superpowers/specs/2026-11-17-notch-hub-design.md` — read it before any task; section numbers below (§n) refer to it.

## Global Constraints

- Minimum macOS **26.0**: `Package.swift` `platforms: [.macOS("26.0")]` (keep `swift-tools-version:5.10`), `LSMinimumSystemVersion` **26.0** in `scripts/bundle.sh`.
- **No new dependencies.**
- Work on branch `feat/notch-hub`, never on `main`.
- Liquid Glass surfaces only: no custom background/border colors on the hub. System font; `monospacedDigit()` for times and percentages. Geist / `Theme.monoFont` not used in hub UI.
- Colors mean state only: indigo `#4B46F5` light / `#8A86FF` dark = working/interactive; Claude orange `#D97757` = needs you; limit rings indigo, **system red at ≥ 90%**. Never use the system accent color.
- The hub panel **never becomes key** (non-activating, `canBecomeKey == false`). Only the Settings window activates the app.
- Hover open after **150 ms** dwell in the notch zone (notch width + 16 pt each side, menu-bar height); close after **300 ms** outside the hub frame + **30 pt**; pill finished auto-hide **5 s**; hub width **660 pt**; module corner radius **24 pt** continuous, gaps **10 pt**; pill ≈ **380 × 48 pt**.
- Socket: `~/.claude/claude-widget/run/approve.sock`, dir mode **0700**; ack timeout **0.5 s**; decision timeout **30 s**; `tool_input` cap **8192 bytes**; PermissionRequest hook entry synchronous with **`timeout: 60`**, every other entry stays `async: true, timeout: 10`.
- Hook rule: if the app isn't reachable, the hook adds **< 20 ms** and prints nothing.
- Usage feed: `GET https://api.anthropic.com/api/oauth/usage`, headers `Authorization: Bearer <token>` and `anthropic-beta: oauth-2025-04-20`. Token from `/usr/bin/security find-generic-password -s "Claude Code-credentials" -w` → JSON `claudeAiOauth.accessToken`. **Never** log/print/persist the token, never send it anywhere else, never refresh it. Poll every **300 s**; refresh on hub open if last success > **60 s** old; failure backoff **60 s doubling to 1800 s**; 401/403 → expired state, retry every **1800 s**. Cache (no secrets) at `~/.claude/claude-widget/limits.json`.
- Deny message copy: **"Denied from the notch"**. Empty state copy: **"No sessions. The critter sleeps."** Expired copy: **"Sign-in expired · open Claude Code"**. Failure copy: **"Limits unavailable"**.
- `HooksConfigMerger` must never modify entries that aren't ours (marker substring `claude-widget-hook`).
- Tests are XCTest in `Tests/ClaudeWidgetCoreTests`; only Core is unit-tested. App tasks are verified by build + run + screenshot (`screencapture -x -R x,y,w,h out.png`, run with the Bash sandbox disabled; have the app print its panel frame).
- Commits: conventional prefixes (`feat:`/`refactor:`/`docs:`/`test:`), ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. SwiftPM builds need the Bash sandbox disabled (clang module cache).

## Review Focus

1. **Stale socket file, app dead** (crash left `approve.sock` behind) → hook must fall through instantly, not wait 0.5 s. Pinned in Task 4.
2. **Huge or truncated `tool_input`** (a 20 KB heredoc command) → must never be Allow-able from the notch, since Gleb can't see all of it. Pinned in Task 3.
3. **Replies coalesced or split across reads** (`{"ack":true}\n{"decision":"allow"}\n` in one write, or one line in two writes) → client must still read both lines correctly. Pinned in Task 4.
4. **Real usage-feed quirks**: `utilization` as Int or Double, `resets_at` with fractional seconds, `null` windows, extra unknown keys → parse without failing. Pinned in Task 2.
5. **Foreign hooks already on `PermissionRequest`** (another tool's sync hook) and an old async widget entry → merger replaces only ours, never duplicates, never touches theirs. Pinned in Task 5.
